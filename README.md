# 我的股票今天怎么了？｜自选股变化提醒

给普通A股用户使用的免费中文 AI Skill。

发股票名称、代码，或一张脱敏后的自选股截图，它会帮你检查最近公告、财报、监管信息和重要日期，再用简单中文说明：

- 最近发生了什么；
- 哪些是已经确认的事实；
- 哪些只是可能的解释；
- 接下来有哪些日期值得留意。

## 它不做什么

不预测涨跌，不给目标价，不推荐买卖，不保证收益，也不会代替持牌投资顾问。

## 最简单的用法

> 帮我看看贵州茅台最近7天发生了什么。

或上传截图并说：

> 检查图里这几只股票，告诉我最需要留意哪一只。

上传截图前，请遮住姓名、证券账号、资金、成本和其他隐私。

## 输出内容

1. 60秒结论；
2. 每只股票的变化和关注级别；
3. 具体证据与来源；
4. 接下来公开的重要日期；
5. 最值得做的一个核实动作；
6. 未核验内容和风险提示。
